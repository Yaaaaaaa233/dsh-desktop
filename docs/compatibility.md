## 插件接口

- Desktop 静态页面来自 `dsh-app://app/`。只使用 `webServer.tapIndex` 的旧注入不能作为 Desktop 适配方案；鲸鱼使用结构化 `webserver/index-inject`。
- 设置页使用官方 `settings.section` 插槽及主题变量，CSS 限定在本插件节点内。
- Host 路由与客户端入口分别声明，发布包必须同时包含它们。
- 插件兼容声明和上游依赖记录在 `catalog.json` 与各自的 package.json 中。

验证细节见 [verification.md](verification.md)。官方更新后，先在隔离环境核对注入、配置接口和原生设置页，再扩展兼容声明。
